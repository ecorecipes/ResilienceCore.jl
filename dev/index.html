ResilienceCore

Resilience and stability metrics that dispatch on what a matrix means. The same numbers can be the Jacobian of a flow at an equilibrium, the Jacobian of a map at a fixed point, a density-independent projection matrix or generator, the period map of a seasonal model, or a Markov kernel. Each metric has methods only for the objects on which it is defined, so asking for, say, the growth rate of an equilibrium Jacobian is a MethodError rather than a number without meaning. applicable_metrics lists what can be computed for an object.

Time semantics reuse DiscreteTime and ContinuousTime from StructuredPopulationCore, the shared core of the ecorecipes projection-model packages.

A dash is a MethodError; applicable_metrics gives the list for any object. Norms default to the Euclidean norm for Jacobians (Neubert & Caswell 1997). For projections the default is the 1-norm, i.e. total population (Stott et al. 2011), weighted by the mesh for an integral projection model.

The metrics are tied together by identities that the tests check:

  • the metrics of exp(J Δt) per Δt equal those of J;
  • a rescaled projection matrix has the same transients;
  • growth rate and damping ratio agree with StructuredPopulationCore;
  • a weighted integral-projection kernel gives the same metrics on any mesh.
